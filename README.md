# Namma-Navigator
Agentic AI platform that consumes scattered city data (traffic, outages, events) in real-time. Using Gemini’s multimodal AI + Firebase, it predicts crises, auto-tags citizen reports, and maps the city’s "pulse" 

# Install requirements
pip install -r requirements.txt

# Run the System
python test_run.py

# (Optional) Start continuous monitoring
To run the agent in a loop with scheduled checks and cleanups, execute:

python -m src.continuous_intelligence
